# 发布界面前端 - 环境配置说明

## 开发环境配置

### 1. API 代理配置

开发环境已配置 Vite 代理,自动将 `/publish/api` 请求转发到 `http://localhost:8000`

配置位置: `vite.config.ts`

```typescript
server: {
  port: 5173,
  proxy: {
    '/publish/api': {
      target: 'http://localhost:8000',
      changeOrigin: true
    }
  }
}
```

### 2. 启动开发服务器

```bash
cd cloud/publish/publish-ui
npm install  # 首次运行需要安装依赖
npm run dev  # 启动开发服务器
```

访问地址: `http://localhost:5173`

### 3. 环境变量 (可选)

如需自定义配置,可以创建以下文件:

#### `.env.development` (开发环境)

```
# API 基础路径 (可选,默认使用 /publish/api/v1)
# VITE_API_BASE_URL=/publish/api/v1
```

#### `.env.production` (生产环境)

```
# 生产环境 API 基础路径
# 根据实际部署情况修改
VITE_API_BASE_URL=/publish/api/v1
# 或使用完整 URL
# VITE_API_BASE_URL=https://api.yourdomain.com/publish/api/v1
```

## 生产环境部署

### 1. 构建项目

```bash
npm run build
```

构建产物在 `dist` 目录

### 2. 部署方式

#### 方式一: 静态文件部署

将 `dist` 目录部署到 Nginx/Apache 等 Web 服务器

#### 方式二: 与后端服务同域部署

将 `dist` 目录放在后端静态文件目录,后端统一提供服务

### 3. Nginx 配置示例

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /path/to/dist;
        try_files $uri $uri/ /index.html;
    }

    # API 代理到后端
    location /publish/api {
        proxy_pass http://localhost:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

## 常见问题

### Q: 开发时 API 请求 404?

A: 确保后端服务运行在 `localhost:8000`,检查 `vite.config.ts` 代理配置

### Q: 生产环境 API 请求失败?

A: 检查 `.env.production` 中的 `VITE_API_BASE_URL` 配置

### Q: 登录后刷新页面退出登录?

A: 检查浏览器是否启用 Cookie,以及后端 Cookie 设置是否正确

### Q: 文件上传失败?

A: 检查文件大小、格式是否符合要求,查看 Network 面板错误信息
