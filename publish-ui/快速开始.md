# 发布界面前端 - 快速开始

## 📦 安装依赖

```bash
cd cloud/publish/publish-ui
npm install
```

## 🚀 启动项目

### 开发环境

```bash
npm run dev
```

访问: `http://localhost:5173`

**前提条件**: 确保后端服务运行在 `http://localhost:8000`

### 生产构建

```bash
npm run build
```

构建产物在 `dist` 目录

## 📋 默认账号

开发环境默认账号 (Mock 数据):

- 管理员: `admin` / `admin`
- 普通用户: `user` / `user`

生产环境请连接真实后端 API

## 🔧 配置说明

### API 代理配置

开发环境已配置代理,将 `/publish/api` 请求转发到 `http://localhost:8000`

如需修改后端地址,编辑 `vite.config.ts`:

```typescript
server: {
  proxy: {
    '/publish/api': {
      target: 'http://localhost:8000',  // 修改为你的后端地址
      changeOrigin: true
    }
  }
}
```

### 环境变量 (可选)

创建 `.env.development` 或 `.env.production` 文件:

```bash
# API 基础路径
VITE_API_BASE_URL=/publish/api/v1
```

## 🎯 功能模块

### 1. 设施管理 (Facilities)

- 厂区/线体/工位的树形管理
- 创建、编辑、删除操作
- 搜索过滤功能

### 2. 驱动包管理 (Drivers)

- 上传 Java/Python/C++ 驱动包
- 发布、下架、撤回操作
- 按类型和状态筛选

### 3. AutoUnit 包管理 (AutoUnit)

- 上传 Python 包
- 状态管理 (已发布/未发布/测试中)
- 卡片式展示

### 4. 界面管理 (Interfaces)

- 创建自动化交互界面
- 配置布局类型
- 工位绑定

### 5. 部署清单管理 (Deployment)

- 上传 TOML 配置文件
- 清单信息管理
- 文件下载

### 6. 操作日志 (Logs)

- 查看系统操作记录
- 多维度筛选
- 导出 CSV

## 🔐 权限说明

- **管理员**: 拥有所有权限
- **普通用户**: 根据 `permissions` 数组控制

权限检查方法:

```typescript
const userStore = useUserStore();
userStore.hasPermission("facility:create"); // 检查单个权限
userStore.isAdmin(); // 是否管理员
```

## 📝 开发规范

### 1. API 调用

使用统一封装的 API 方法:

```typescript
import * as facilitiesApi from "@/api/facilities";

const data = await facilitiesApi.getFacilitiesTree();
```

### 2. 错误处理

响应拦截器已统一处理,无需手动处理 401/403 等错误

### 3. 文件上传

使用 `FormData` 格式:

```typescript
await api.uploadFile({
  file: fileObject,
  name: "filename",
  ...otherParams,
});
```

### 4. 文件下载

使用 Blob 方式:

```typescript
const response = await api.downloadFile(id);
const url = window.URL.createObjectURL(new Blob([response.data]));
// ... 创建 <a> 标签下载
```

## ❓ 常见问题

**Q: 登录后立即退出?**
A: 检查后端 Token 是否正确设置 Cookie

**Q: API 请求 404?**  
A: 确认后端服务运行在 localhost:8000,检查代理配置

**Q: 上传文件失败?**
A: 检查文件格式和大小,查看 Network 错误信息

**Q: 刷新页面状态丢失?**
A: Token 和用户信息已持久化到 localStorage,检查是否被清除
