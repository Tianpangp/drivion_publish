# AutoUnit 与 HAL 制品包规范

## 1. 通用规则

- 单个上传包最大 100 MiB。
- 支持 ZIP 和 tar 系列归档；Exe DevKit 默认应生成 ZIP。
- 上传表单只包含 `file`，名称、版本和入口必须从包内解析。
- Publish 按原始字节计算 MD5 和 SHA-256，Exe 必须以 SHA-256 为完整性标准。
- 归档内目标元数据文件必须且只能出现一次，可以位于顶层或单个项目根目录下。
- 不要放入密码、Token、现场秘密或设备实例凭据。

## 2. AutoUnit 包

AutoUnit 归档必须且只能包含一个 `drivion.project.json`。

最小示例：

```json
{
  "name": "上料自动化逻辑",
  "package_id": "feeding.logic",
  "version": "1.4.2",
  "module": "feeding_logic"
}
```

| 字段 | 必填 | 说明 |
| --- | :---: | --- |
| `name` | 是 | 人类可读的展示名称 |
| `package_id` | 是 | AutoUnit 稳定身份，建议用小写点分名称 |
| `version` | 是 | 精确版本，建议使用 SemVer |
| `module` | 是 | Exe 加载的 Python 顶层模块 |
| `description` | 否 | 功能说明 |
| `python_version` | 否 | 建议的 Python 版本约束 |
| `dependencies` | 否 | 依赖列表，HAL 建议使用结构化 `name/version` |
| `readme` | 否 | 简短使用说明 |
| `changelog` | 否 | 本版本变更说明 |

HAL 依赖建议格式：

```json
{
  "dependencies": [
    {"name": "drivion-motion-hal", "version": "2.1.0"},
    {"name": "drivion-vision-hal", "version": "1.3.4"}
  ]
}
```

`name` 必须和 HAL `pyproject.toml` 的 `project.name` 完全一致，`version` 必须是精确版本，不使用 `latest`、`*`或版本范围。Publish 保存并原样返回 `dependencies`；Exe 负责解析。

AutoUnit 版本唯一键是 `package_id + version`。覆盖更新时两者必须与原记录一致。

## 3. HAL 驱动包

HAL 归档必须且只能包含一个 `pyproject.toml`。当前 HAL 都是 Python 包，不需要额外上传“驱动类型”字段。

最小示例：

```toml
[build-system]
requires = ["setuptools>=68", "wheel"]
build-backend = "setuptools.build_meta"

[project]
name = "drivion-motion-hal"
version = "2.1.0"
requires-python = ">=3.10"

[project.entry-points."drivion.hal_drivers"]
main = "drivion_motion_hal.driver:register"
```

Publish 校验 `project.name`、`project.version` 和至少一个 `drivion.hal_drivers` entry point。HAL 版本唯一键是 `project.name + project.version`，覆盖更新时两者均不得变化。HAL 不和设备建立 Publish 绑定记录。

## 4. 推荐归档结构

```text
feeding-logic-1.4.2.zip
  drivion.project.json
  pyproject.toml
  src/feeding_logic/
  ui/schema.json

drivion-motion-hal-2.1.0.zip
  pyproject.toml
  src/drivion_motion_hal/
```

## 5. Exe 安装安全要求

- 校验服务端返回的 `size` 和 `sha256`。
- 解压前检查成员路径，拒绝绝对路径和 `..` 路径穿越。
- 限制解压后总大小和文件数，避免压缩炸弹。
- 不要原地覆盖正在运行的版本。
- 只有 AutoUnit 和全部 HAL 都校验成功后才更新当前版本指针。
- 保留上一个已验证版本，供 Exe 本地回滚。
